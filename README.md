# 🚀Full-Stack AI Career Development Platform

An AI-powered career development platform that helps users build resumes, generate cover letters, prepare for interviews, and explore industry insights.

## ✨ Features

- 🔐 Secure authentication with Clerk
- 📄 AI Resume Builder
- ✉️ AI Cover Letter Generator
- 🎤 AI Mock Interview
- 📊 Industry Insights & Salary Trends
- 📥 Resume PDF Download
- 📱 Responsive UI

## 🛠️ Tech Stack

- Next.js
- React
- Tailwind CSS
- shadcn/ui
- Prisma ORM
- PostgreSQL
- Clerk Authentication
- Google Gemini AI

## 🚀 Getting Started

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```

## 🔑 Environment Variables

Create a `.env` file and add:

```env
DATABASE_URL=
GEMINI_API_KEY=
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
```
